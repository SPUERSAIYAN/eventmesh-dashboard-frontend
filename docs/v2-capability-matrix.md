# V2 需求能力覆盖矩阵

页面仅适配当前后端源码中已验证可查询，或能够真实持久化并刷新形成闭环的能力。

| 状态 | 能力 |
| --- | --- |
| 已接入 | 集群列表、创建集群表单、集群树、Runtime 列表与详情、Topic 列表、按集群/Topic 查询消费组、配置只读、操作日志 |
| 前端组合 | 关系图与资源树；资源树包含集群、Runtime、Topic、消费组，虚拟目录不代表后端拓扑边 |
| 后端待闭环 | 普通集群创建当前仍会因必填字段未赋值而回滚；前端保留真实错误态，不伪造成功 |
| 暂不开放 | 登录、组织成员、角色权限、EventMesh 空间创建、直接关联集群查询、连接、ACL、健康、配置更新、Runtime 创建、Topic 创建/删除、消费组删除 |

验收要求：空列表显示真实空态；业务错误明确失败；部分接口失败保留成功数据；不生成模拟指标；前端不得请求“暂不开放”接口。
